# davidmrtns-site

Personal website for `davidmrtns.dev`.

## Local preview

No build step is required. Open `index.html` in your browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Cloudflare Pages

- Framework preset: **None**
- Build command: leave empty
- Build output directory: `/` (or `.` if the dashboard requires a relative path)
- Root directory: `/`

This is a plain static HTML/CSS/JS site.
